# Vmux Project Notes

- Product name: Vmux.
- Stack: Tauri 2, React, TypeScript, Vite, Tailwind CSS v4, TanStack Query.
- UI direction: compact Warm Academic operational app. Keep the first screen as the service control surface.
- Backend boundary: use typed Tauri commands for service configuration, process lifecycle, logs, and open-path/open-url behavior.
- Avoid marketing pages, decorative gradients, nested cards, and broad unrelated refactors.
